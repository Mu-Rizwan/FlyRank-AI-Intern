
# Polite Scraper - Books to Scrape

## Target Classification

- **Target site**: https://books.toscrape.com/
- **Why this site**: It's a public sandbox explicitly built for practicing web scraping. The site's homepage states: "Welcome to Books to Scrape! This is a sandbox website for practicing web scraping."
- **Scope**: First 3 catalogue pages only (60 books total).
- **Data collected**: Title, product URL, price, availability, rating, description, source page, and fetch timestamp.
- **Robots.txt**: https://books.toscrape.com/robots.txt - Checked and confirmed.

**Ethics statement**: I will not reuse this code on another site without checking its rules and terms first.
